# Rounds

A rounding aide for post-op urologic oncology patients, built for iPhone (Add to Home Screen).

- Manual census, AM/PM progress notes with button-based subjective questions and exam findings
- Generates plain-text notes to copy or share into email
- **All patient data is stored only on the device** (browser localStorage). Nothing is sent to any server; this repository contains only the app code.

Button lists and procedure templates live in `js/templates.js`.
